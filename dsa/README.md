# DSA interview prep

Interview-prep notes for a junior backend engineer. Order follows the classic
patterns-first curriculum (NeetCode/Blind-75 style): the patterns you'll see
in coding rounds, each with the interview angle and the Python shape of the
solution. Notes are **AI-drafted and must be verified against their Further reading**
— every claim cites a source people can trust (Python docs, Wikipedia,
Tech Interview Handbook, GeeksforGeeks, NeetCode).

Add a note per pattern; list it below in the order you intend to study it —
`/dsa` renders in this order.
